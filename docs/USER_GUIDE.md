# User Guide

How to use the Online Exam System as a student.

---

## Getting Started

### Step 1: Register

1. Go to the application URL
2. Click **"Create Account"**
3. Fill in your details:
   - Full Name
   - Email Address
   - Password (minimum 6 characters)
   - Select **"Student"** as role
4. Click **"Register"**
5. You'll be automatically logged in

### Step 2: Login

1. Go to the application URL
2. Enter your email and password
3. Click **"Sign In"**
4. You'll be redirected to your dashboard

---

## Dashboard Overview

### My Learning Tab

Shows courses you're enrolled in:
- Course title and description
- Course status (Enrolled, Locked)
- **"View Exams"** button (when enrolled)

### Explore Courses Tab

Shows all available courses:
- Course title and description
- Course price
- **"Buy Now"** button (to enroll)

### My Results Tab

Shows all your exam results:
- Filter options: All, Passed, Pending, Failed
- Exam title and course name
- Score and status
- **"View Details"** button
- **"Certificate"** button (for passed exams)

---

## Enrolling in a Course

### Step 1: Browse Courses

1. Click **"Explore Courses"** tab
2. Browse available courses
3. Find a course you want to take

### Step 2: Enroll

1. Click **"Buy Now"** on a course
2. Select payment method:
   - **UPI/GPay** — Scan QR code and enter transaction ID
   - **Cash** — Enter reference note
3. Enter transaction ID or reference
4. Click **"Submit Request"**
5. Wait for admin approval

### Step 3: Wait for Approval

1. Admin will review your enrollment
2. You'll see the course in **"My Learning"** tab once approved
3. Status changes from "Pending" to "Enrolled"

---

## Taking an Exam

### Step 1: Access Exam

1. Go to **"My Learning"** tab
2. Find your enrolled course
3. Click **"View Exams"**
4. Click **"Start Exam"**

### Step 2: Read Instructions

The exam instructions page shows:
- Exam title and description
- Duration (time limit)
- Maximum marks
- Pass marks
- Rules and warnings

**Important Rules:**
- Timer starts immediately and cannot be paused
- Tab switching is monitored
- 3 tab-switch warnings = auto-submit
- You have one attempt per exam

### Step 3: Start Exam

1. Click **"Start Exam"** on instructions page
2. Timer starts immediately
3. First question appears

### Step 4: Answer Questions

**For MCQ Questions:**
1. Read the question
2. Select one of the four options
3. Click **"Save & Next"** to save and move to next question

**For Subjective Questions:**
1. Read the question
2. Type your answer in the text area
3. Click **"Save & Next"** to save and move to next question

**Navigation Options:**
- **Save & Next** — Save current answer and move to next question
- **Mark for Review** — Mark question for later review
- **Save & Mark** — Save answer and mark for review
- **Skip** — Move to next question without saving

### Step 5: Submit Exam

1. Review your answers using the question navigator (right sidebar)
2. Click **"Submit Exam"**
3. Confirm submission
4. See your result immediately (MCQ) or "Pending" (Subjective)

---

## Understanding Results

### MCQ Exam Results

After submitting an MCQ exam, you'll see:
- **PASSED** (green) — You scored above the pass marks
- **FAILED** (red) — You scored below the pass marks
- Score: X / Y marks

### Subjective Exam Results

After submitting a subjective exam:
- Status shows **"Pending"**
- Admin will review and grade your answers
- Check back later for final results

### Viewing Detailed Results

1. Go to **"My Results"** tab
2. Click **"View Details"** on any exam
3. See:
   - Each question
   - Your answer
   - Correct answer (if wrong)
   - Marks awarded

## Downloading Certificates

### When Available

Certificates are available when:
- You've passed at least one exam in a course
- The exam has been graded (MCQ immediately, Subjective after admin review)

### How to Download

1. Go to **"My Results"** tab
2. Find a **"Passed"** exam
3. Click **"Certificate"** button
4. PDF certificate downloads automatically

### Certificate Contents

The certificate includes:
- Your name
- Course title
- Exam title
- Score achieved
- Date of completion

## Handling Locked Courses

### When Does a Course Lock?

A course locks when you fail 3 exams in that course.

### What Happens When Locked?

- You can't take any more exams in that course
- Status shows **"Course Locked"**
- You see a message: "Contact the administrator"

### How to Unlock?

1. Contact the administrator
2. Explain your situation
3. Admin can unlock your access
4. You get 1 more attempt

## Troubleshooting

### Can't Login

- Check your email and password
- Make sure you're using the correct URL
- Clear browser cache
- Try different browser

### Course Not Showing in My Learning

- Wait for admin approval
- Check enrollment status
- Refresh the page
- Log out and log back in

### Exam Not Loading

- Check your internet connection
- Refresh the page
- Clear browser cache
- Contact support if problem persists

### Can't Download Certificate

- Make sure you've passed an exam
- Check if exam has been graded
- Try different browser
- Contact support if problem persists

### Tab Switch Warning

- Don't switch tabs during exam
- Don't minimize browser
- Don't open new windows
- Stay focused on exam page

## FAQ

**Q: Can I retake an exam?**
A: No. You have one attempt per exam.

**Q: What if I fail all exams?**
A: After 3 failures, the course locks. Contact admin to unlock.

**Q: How long is the exam?**
A: Check the duration shown on the exam instructions page.

**Q: Can I pause the exam?**
A: No. The timer runs continuously.

**Q: What if I get disconnected?**
A: Your answers are saved automatically. Reconnect and continue.

**Q: When will I get my certificate?**
A: Immediately after passing an MCQ exam. After admin grades subjective exams.

**Q: Can I see correct answers?**
A: Yes. Click "View Details" on any exam to see correct answers.

**Q: What if I accidentally submit?**
A: Submission is final. You cannot undo it.
